# Improving teach

Living notes from our discussion. Update as ideas, preferences, and decisions develop.

## Context

1. Improve the existing `teach` skill through exploration, using Matt Pocock's skills and independent ideas as references.
2. Keep the skill simple and refine it through use. It currently supports small lessons, concrete examples, practice, feedback, and adapting to the user's understanding and purpose.
3. The immediate learning interest is how a collection of skills supports software development, starting with the overall process.
4. `teach` is user-only. These notes have not changed the skill or its invocation policy.

## Ideas from Matt Pocock

Source: [teach](https://github.com/mattpocock/skills/blob/main/skills/productivity/teach/SKILL.md).

1. Give each lesson a practical outcome: something the user can explain or do afterward.
2. Revisit earlier learning through recall and application.
3. Keep brief progress records across sessions, including understanding, difficulties, and next steps.
4. Ground lessons in reliable sources and provide references for further learning.
5. Matt's implementation uses a teaching workspace with a mission, resources, learning records, HTML lessons, and reference files. Adopting that structure is optional and has not been agreed.

## Independent suggestions

1. Show a brief topic map before teaching details, then locate each lesson within it. This follows the user's interest in understanding the overall collection of software skills.
2. Check understanding through application. For example, ask the user to choose a skill for a realistic task and explain why.
3. Make questions purposeful. Answer direct questions directly and avoid turning every response into a quiz.
