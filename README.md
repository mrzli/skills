# Agent Skills

Reusable skills for AI agents.

## Skills

### [Productivity](skills/productivity)

| Skill | Description |
| --- | --- |
| [elif](skills/productivity/elif/SKILL.md) | Rephrase the last response with more context, simpler language, and the repository's terminology. |
| [explore](skills/productivity/explore/SKILL.md) | Clarify a vague interest or problem through questions and small next steps. |
| [handoff](skills/productivity/handoff/SKILL.md) | Summarize a session so another agent can continue the work. |
| [interrogate](skills/productivity/interrogate/SKILL.md) | Stress-test a plan or idea through structured rounds of questions. |
| [restate](skills/productivity/restate/SKILL.md) | Restate the user's goals and the problem they are trying to solve. |
| [teach](skills/productivity/teach/SKILL.md) | Teach a topic through lessons that track the user's progress across sessions. |
| [tidy-docs](skills/productivity/tidy-docs/SKILL.md) | Review and clean up documentation in a repository. |
| [writing-agents](skills/productivity/writing-agents/SKILL.md) | Guide the writing of `AGENTS.md` files. |
| [writing-skills](skills/productivity/writing-skills/SKILL.md) | Guide the writing of agent skills. |
| [writing-text](skills/productivity/writing-text/SKILL.md) | Make text concise, clear, and direct. |
