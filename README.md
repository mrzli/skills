# Agent Skills

Reusable skills for AI agents.

## Skills

| Skill | Description |
| --- | --- |
| [elif](.agents/skills/elif/SKILL.md) | Rephrase the last response with more context, simpler language, and the repository's terminology. |
| [explore](.agents/skills/explore/SKILL.md) | Clarify a vague interest or problem through questions and small next steps. |
| [handoff](.agents/skills/handoff/SKILL.md) | Summarize a session so another agent can continue the work. |
| [interrogate](.agents/skills/interrogate/SKILL.md) | Stress-test a plan or idea through structured rounds of questions. |
| [teach](.agents/skills/teach/SKILL.md) | Teach a topic through lessons that track the user's progress across sessions. |
| [tidy-docs](.agents/skills/tidy-docs/SKILL.md) | Review and clean up documentation in a repository. |
| [writing-agents](.agents/skills/writing-agents/SKILL.md) | Guide the writing of `AGENTS.md` files. |
| [writing-skills](.agents/skills/writing-skills/SKILL.md) | Guide the writing of agent skills. |
| [writing-text](.agents/skills/writing-text/SKILL.md) | Make text concise, clear, and direct. |
